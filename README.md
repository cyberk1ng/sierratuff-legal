# SierraTuff — legal

Public home for SierraTuff's legal documents, kept in its own repository so the
application repository can stay private.

- **[Privacy Policy](https://cyberk1ng.github.io/sierratuff-legal/)** — the URL given to
  the Google Play Console.

`PRIVACY.md` is the readable source; `index.html` is what GitHub Pages serves. They say
the same thing, and the source of truth is `PRIVACY.md` in the application repository —
edit it there first, then copy it here.
